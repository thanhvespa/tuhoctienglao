# Chương 5 – Bài 1: Đồ Dùng, Quần Áo, Màu Sắc & Kích Cỡ

> [!info] Thông tin bài học
> - **Thời lượng:** 30–60 phút
> - **Mục tiêu Nghe – Nói:** Gọi tên quần áo, vật dụng hằng ngày, đọc tên 8 màu sắc cơ bản và miêu tả kích cỡ (lớn, nhỏ, dài, ngắn, vừa, chật, rộng).

---

## 1. Quy Tắc Ghép Màu Sắc & Kích Cỡ (Siêu Giống Tiếng Việt!)

Trong tiếng Lào, **Màu sắc và Tính từ đứng SAU Danh từ** giống hệt tiếng Việt!
- *"Áo màu đỏ"* = `ເສື້ອ` (*xựa* - áo) + `ສີແດງ` (*sỉ đeng* - màu đỏ) → **ເສື້ອສີແດງ** (*xựa sỉ đeng*)
- *"Quần ngắn (quần đùi)"* = `ໂສ້ງ` (*xộng* - quần) + `ຂາສັ້ນ` (*khả xặn* - ống ngắn) → **ໂສ້ງຂາສັ້ນ** (*xộng khả xặn*)
- *"Giày cỡ lớn"* = `ເກີບ` (*kợp* - giày) + `ເບີໃຫຍ່` (*bơ nhày* - cỡ lớn) → **ເກີບເບີໃຫຍ່** (*kợp bơ nhày*)

> **Ghi chú:** Lưu ý từ vựng Lào vs Thái
> Trong giao tiếp đời thường ở Viêng Chăn, người Lào gọi **"cái quần"** là **`ໂສ້ງ` (*xộng*)** (chứ ít khi dùng *kang kêng*). Còn chiếc váy truyền thống của phụ nữ Lào là **`ສິ້ນ` (*xịn*)**.

## 2. Từ Vựng Quần Áo, Màu Sắc & Kích Cỡ (18 Từ)

### Quần áo & Đồ dùng
| Tiếng Việt | Chữ Lào | Phiên âm Việt | Ghi chú |
| :--- | :--- | :--- | :--- |
| Áo | ເສື້ອ | xựa | Áo thun = `ເສື້ອຍືດ` (*xựa nhựt*) |
| Quần | ໂສ້ງ | xộng | Quần dài = `ໂສ້ງຂາຍາວ` |
| Váy truyền thống Lào | ສິ້ນ | xịn | |
| Giày / Dép | ເກີບ | kợp | Khép môi ở `-p` |
| Mũ / Nón | ໝວກ | muộc | Khép `-k` |
| Túi xách / Ba lô | ກະເປົາ | ka-pau | |
| Điện thoại / SIM | ໂທລະສັບ / ຊິມ | thô-la-xắp / xim | |
| Kính mắt | ແວ່ນຕາ | vèn ta | |

### Màu sắc (`ສີ` = màu)
| Tiếng Việt | Chữ Lào | Phiên âm Việt |
| :--- | :--- | :--- |
| Trắng / Đen | ສີຂາວ / ສີດຳ | sỉ khảo / sỉ đăm |
| Đỏ / Vàng | ສີແດງ / ສີເຫຼືອງ | sỉ đeng / sỉ lương |
| Xanh dương / Xanh lá | ສີຟ້າ / ສີຂຽວ | sỉ fạ / sỉ khỉu |
| Hồng / Nâu | ສີຊົມພູ / ສີນ້ຳຕານ | sỉ xôm-p'hu / sỉ nặm tan |

### Kích cỡ (`ໄຊ້ / ເບີ` = size/cỡ)
| Tiếng Việt | Chữ Lào | Phiên âm Việt | Ghi chú |
| :--- | :--- | :--- | :--- |
| To (lớn) / Nhỏ | ໃຫຍ່ / ນ້ອຍ | nhày / nọi | |
| Vừa vặn | ພໍດີ | p'ho đi | `p'h` bật hơi! |
| Chật / Rộng | ແໜ້ນ (ຄັບ) / ຫຼວມ | nẹn (khắp) / luổm | |
| Dài / Ngắn | ຍາວ / ສັ້ນ | nhao / xặn | |

## 3. Mẫu Câu Miêu Tả & Hỏi Size/Màu

- **Cái áo màu trắng này đẹp quá!** → ເສື້ອສີຂາວນີ້ງາມຫຼາຍ! (*Xựa sỉ khảo nị ngam lai!*)
- **Bạn có màu khác không?** → ມີສີອື່ນບໍ່? (*Mi sỉ ừn bò?*)
- **Cái này rộng quá / chật quá.**
  - ອັນນີ້ຫຼວມໂພດ. (*Ăn nị luổm p'hốt.*)
  - ອັນນີ້ແໜ້ນໂພດ. (*Ăn nị nẹn p'hốt.*)
- **Vừa vặn lắm, đẹp lắm!** → ພໍດີເລີຍ, ງາມຫຼາຍ! (*P'ho đi lơi, ngam lai!*)

# Chương 5 – Bài 2: Trả Giá & Chọn Hàng Hóa Ở Chợ / Cửa Hàng

> [!info] Thông tin bài học
> - **Thời lượng:** 30–60 phút
> - **Mục tiêu Nghe – Nói:** Hỏi xem và mặc thử đồ, hỏi chất lượng tốt hay không, so sánh chọn cái khác và trả giá lịch sự để được giảm giá khi đi chợ ở Lào.

---

## 1. Bí Quyết Mua Sắm & Trả Giá Ở Chợ Lào

Khác với việc cò kè gay gắt, ở Lào bạn càng **tươi cười, nói mềm mỏng** với `ແດ່ / ເດີ້` thì người bán càng dễ giảm giá (`ຫຼຸດລາຄາ`).
- Ở siêu thị hoặc trung tâm thương mại: Giá niêm yết sẵn (`ລາຄາຕາຍໂຕ` - không bớt).
- Ở chợ sáng (`ຕະຫຼາດເຊົ້າ`), chợ đêm (`ຕະຫຼາດມືດ`): Có thể trả giảm khoảng 15–30% một cách vui vẻ!

---

## 2. Từ Vựng Mua Sắm & Thương Lượng (14 Từ)

| Tiếng Việt | Chữ Lào | Phiên âm Việt | Lưu ý |
| :--- | :--- | :--- | :--- |
| Mua | ຊື້ | xự | |
| Bán | ຂາຍ | khải | Chú ý kéo dài `ai` |
| Đồ đạc / Hàng hóa | ເຄື່ອງ | khương | Đi mua sắm = `ໄປຊື້ເຄື່ອງ` |
| Thử / Thử xem | ລອງ / ລອງເບິ່ງ | loong / loong bờng | Mặc thử = `ລອງໃສ່` |
| Chất lượng tốt | ຄຸນນະພາບດີ / ດີ | khun-na-p'hạp đi / đi | Nói gọn `ແທ້ບໍ່?` (hàng thật không?) |
| Mới / Cũ | ໃໝ່ / ເກົ່າ | mày / kàu | |
| Đẹp / Xấu | ງາມ / ບໍ່ງາມ (ຂີ້ຮ້າຍ) | ngam / bò ngam | `ບໍ່ງາມ` lịch sự hơn `ຂີ້ຮ້າຍ` |
| Khác / Cái khác | ອື່ນ / ອັນອື່ນ | ừn / ăn ừn | |
| Hơn | ກວ່າ | quà | To hơn = `ໃຫຍ່ກວ່າ` (*nhày quà*) |
| Giảm giá | ຫຼຸດລາຄາ | lút la-kha | `ຫຼຸດໃຫ້ແດ່` = bớt cho với |
| Bao nhiêu tiền? | ເທົ່າໃດ? / ທໍ່ໃດ? | thào đay? / thò đay? | |
| Lấy cái này | ເອົາອັນນີ້ | au ăn nị | |
| Chỉ xem thôi | ເບິ່ງຊື່ໆ | bờng xừ xừ | Dùng khi chưa muốn mua! |
| Giá cuối (không bớt nữa) | ລາຄາສຸດທ້າຍ | la-kha xút thại | |

## 3. Mẫu Câu Thực Chiến Khi Chọn Đồ & Trả Giá

1. **Khi mới ghé sạp hàng:**
   - ຂໍເບິ່ງແດ່ເດີ້. → *Khỏ bờng đè đơ.* (Cho em xem chút nhé.)
   - ຂໍເບິ່ງຊື່ໆເດີ້, ຂອບໃຈ. → *Khỏ bờng xừ xừ đơ, khọp chay.* (Em chỉ xem thôi nha, cảm ơn — giúp thoát khéo!)
2. **Hỏi thử đồ & chọn cái khác:**
   - ຂໍລອງໃສ່ໄດ້ບໍ່? → *Khỏ loong xày đạy bò?* (Cho thử mặc được không?)
   - ມີອັນໃໝ່ກວ່ານີ້ບໍ່? → *Mi ăn mày quà nị bò?* (Có cái nào mới hơn cái này không?)
   - ມີອັນຖືກກວ່ານີ້ບໍ່? → *Mi ăn thực quà nị bò?* (Có cái nào rẻ hơn cái này không?)
3. **Trả giá khéo léo:**
   - ຫຼຸດລາຄາໃຫ້ແດ່ໄດ້ບໍ່? → *Lút la-kha hay đè đạy bò?* (Giảm giá cho mình chút được không?)
   - ຂ້ອຍຊື້ສອງອັນ, ຫຼຸດໃຫ້ແດ່ເດີ້! → *Khọi xự xỏng ăn, lút hay đè đơ!* (Tôi mua 2 cái, bớt cho nha!)

# Chương 5 – Bài 3: Thanh Toán, Đổi Tiền & Nhận Hóa Đơn

> [!info] Thông tin bài học
> - **Thời lượng:** 30–60 phút
> - **Mục tiêu Nghe – Nói:** Hỏi hình thức thanh toán (tiền mặt hay quét mã chuyển khoản), đổi tiền Việt/USD/Baht sang tiền Kíp, kiểm tra tiền thối, xin túi đựng và hóa đơn.

---

## 1. Thực Tế Thanh Toán Tại Lào Hiện Nay

Tại Lào (Viêng Chăn, Luang Prabang, Vang Vieng), **chuyển khoản / quét mã QR (`ໂອນເງິນ` *ôn ngơn*, đặc biệt qua BCEL One)** phổ biến khắp mọi nơi từ siêu thị tới quán nước vỉa hè. Tuy vậy tiền mặt (`ເງິນສົດ` *ngơn sốt*) và đổi tiền (`ແລກເງິນ` *lẹk ngơn*) ở quầy vẫn rất cần thiết cho người Việt sang công tác, du lịch!

---

## 2. Từ Vựng Thanh Toán & Giao Dịch Tiền Tệ (14 Từ)

| Tiếng Việt | Chữ Lào | Phiên âm Việt | Ghi chú |
| :--- | :--- | :--- | :--- |
| Trả tiền / Thanh toán | ຈ່າຍເງິນ | chài ngơn | |
| Tiền mặt | ເງິນສົດ | ngơn sốt | Khép `-t` |
| Chuyển khoản / Quét mã | ໂອນເງິນ / ສະແກນ | ôn ngơn / xa-ken | |
| Thẻ ngân hàng | ບັດ | bắt | `ຮັບບັດບໍ່?` = Có nhận thẻ không? |
| Đổi tiền | ແລກເງິນ | lẹk ngơn | |
| Tỷ giá | ອັດຕາແລກປ່ຽນ | ắt-ta lẹk piền | |
| Tiền thối (tiền thừa) | ເງິນທອນ | ngơn thon | `th` bật hơi |
| Hóa đơn / Biên lai | ໃບບິນ / ໃບຮັບເງິນ | bay bin / bay hắp ngơn | |
| Túi (đựng đồ) | ຖົງ | thổng | Túi nilon = `ຖົງຢາງ` |
| Quầy thu ngân | ບ່ອນຈ່າຍເງິນ | bòn chài ngơn | |
| Đếm | ນັບ | nắp | Khép `-p` |
| Đủ / Thiếu | ຄົບ / ຂາດ | khốp / khạt | `kh` bật hơi |
| Tiền Việt / Tiền Đô / Tiền Thái | ເງິນດົງ / ເງິນໂດລາ / ເງິນບາດ | ngơn đồng / ngơn đô-la / ngơn bạt | |
| Nhận | ຮັບ | hắp | `ຮ` = `h`! |

## 3. Mẫu Câu Giao Dịch Ở Quầy Thu Ngân & Quầy Đổi Tiền

1. **Khi thanh toán ở cửa hàng / siêu thị:**
   - ຈ່າຍຢູ່ໃສ? → *Chài yù xảy?* (Trả tiền ở đâu?)
   - ໂອນເງິນໄດ້ບໍ່? / ຮັບເງິນສົດບໍ່? → *Ôn ngơn đạy bò? / Hắp ngơn sốt bò?* (Chuyển khoản được không? / Nhận tiền mặt không?)
   - ຂໍຖົງແດ່, ກັບ ຂໍໃບບິນແດ່. → *Khỏ thổng đè, kắp khỏ bay bin đè.* (Cho xin túi với, và cho xin hóa đơn nhé.)
2. **Khi kiểm tra tiền thối:**
   - ຂໍໂທດ, ເງິນທອນຂາດສິບພັນກີບ. → *Khỏ thốt, ngơn thon khạt síp p'hăn kíp.* (Xin lỗi, tiền thối bị thiếu 10 nghìn kíp.)
3. **Khi đổi tiền ở ngân hàng / tiệm vàng:**
   - ຂ້ອຍຢາກແລກເງິນໂດລາເປັນເງິນກີບ. → *Khọi yạk lẹk ngơn đô-la pên ngơn kíp.* (Tôi muốn đổi tiền Đô sang tiền Kíp.)
   - ອັດຕາແລກປ່ຽນມື້ນີ້ເທົ່າໃດ? → *Ắt-ta lẹk piền mự nị thào đay?* (Tỷ giá hôm nay bao nhiêu?)
